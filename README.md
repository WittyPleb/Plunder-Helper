# Plunder Helper

This plugin lets you highlight objects & NPCs within Pyramid Plunder. It can even send a notification when the cat appears!

The colors, opacity, and all other settings are completely customizable.

You can access the settings by pressing the plugin's button.

Some of the available options are:

- Highlighting the Guardian Mummy
- Highlighting urns, chests, and sarcophagus
- Highlighting the cat & sending a notification when it appears
- Highlighting enemies that may appear
